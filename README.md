# Atlas de Riesgo · muestra de formato

Muestra del formato propuesto para la actualización 2026 del **Atlas de Riesgo para
la Georreferenciación de las Violencias contra las Mujeres en el Estado de Puebla**.

Documento interactivo: https://xgv85.github.io/atlas-riesgo-puebla-muestra/

No es el documento final. Reúne un apartado de cada tipo —texto, cifras clave,
cartografía, matriz municipal, perfiles y ficha de indicador— para mostrar cómo se
comportan en un documento electrónico.

Todas las cifras son reales y corresponden al ejercicio 2022, el mismo que publica la
edición vigente del Atlas; proceden del CEDAVIM y de las proyecciones de población de
CONAPO, y reproducen las cifras municipales ya publicadas en esa edición. La identidad
gráfica y los logotipos son provisionales.
